Grid Layout em CSS

CSS Grid é um sistema de layout bidimensional: permite organizar elementos em linhas e colunas ao mesmo tempo.

Definindo colunas e espaçamento

grid-template-columns define as colunas e gap cria espaço entre as células.

1
2
3
4
5
6
display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 12px;

Colunas responsivas

minmax() define o tamanho mínimo e máximo das colunas. Com auto-fit, o Grid adapta a quantidade de colunas ao espaço disponível.

Card 1
Card 2
Card 3
Card 4
grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));

Posicionando itens

Um item pode ocupar mais de uma coluna ou linha com grid-column e grid-row.

Item que ocupa duas colunas
Item 2
Item 3
Item 4
grid-column: span 2;

Áreas do layout

grid-template-areas nomeia regiões para montar layouts de forma clara.

Cabeçalho
Menu
Conteúdo principal
Barra lateral
Rodapé
grid-template-areas:
    "cabecalho cabecalho"
    "menu conteudo"
    "lateral conteudo"
    "rodape rodape";
