Introdução ao CSS

CSS (Cascading Style Sheets, ou Folhas de Estilo em Cascata) é a linguagem usada para definir a apresentação de páginas HTML, como cores, fontes, espaçamentos e posicionamento dos elementos.

1. CSS inline

O CSS inline é escrito no atributo style do próprio elemento. É útil para uma demonstração pontual, mas difícil de manter quando aplicado em muitos elementos.

Este parágrafo usa CSS inline.

<p style="color: green;">Texto</p>

2. CSS interno

O CSS interno fica dentro de uma tag <style> no <head> do documento. Ele pode estilizar vários elementos desta página.

Este parágrafo usa a classe definida no CSS interno.

3. CSS externo

O CSS externo fica em um arquivo separado e é conectado ao HTML com <link rel="stylesheet" href="1.9_css.css">. Essa forma facilita a reutilização e a manutenção dos estilos.
