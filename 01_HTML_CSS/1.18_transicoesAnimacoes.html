Transições e Animações em CSS

Transições e animações acrescentam movimento aos elementos. Use-as com moderação para dar retorno visual sem atrapalhar a leitura ou a navegação.

Transições

Uma transição suaviza a mudança de uma propriedade quando ocorre um estado, como passar o cursor ou focar um botão.

transition: background-color 0.3s ease, transform 0.3s ease;

Animações com keyframes

@keyframes define etapas de uma animação. A propriedade animation configura sua duração, repetição e outros detalhes.

Animação
@keyframes deslizar {
    from { transform: translateX(0); }
                to { transform: translateX(min(180px, calc(100vw - 240px))); }
}

animation: deslizar 2s ease-in-out infinite alternate;

Respeito à preferência por movimento reduzido

Algumas pessoas preferem menos movimento. A consulta prefers-reduced-motion permite reduzir ou remover animações conforme a configuração do sistema.
