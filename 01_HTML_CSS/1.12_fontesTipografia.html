Fontes e Tipografia em CSS

Tipografia é a forma como o texto é apresentado. No CSS, propriedades tipográficas ajudam a tornar o conteúdo legível e a criar hierarquia visual.

Família tipográfica

A propriedade font-family define a família da fonte. Informe alternativas para o navegador usar caso a primeira não esteja disponível.

Este texto usa uma família sem serifa, com alternativas de fonte.

font-family: Arial, Helvetica, sans-serif;

Tamanho e peso

font-size controla o tamanho do texto. font-weight controla o peso, como normal ou negrito.

Texto maior para destacar um exemplo.

Texto com peso mais forte.

font-size: 1.25rem;
font-weight: 700;

Estilo, altura da linha e alinhamento

font-style pode aplicar itálico. line-height ajusta o espaço vertical entre linhas e text-align controla o alinhamento do texto.

Uma altura de linha confortável ajuda na leitura de parágrafos longos. Este exemplo mostra como ajustar o espaço entre linhas e alinhar o texto.

Este texto usa estilo itálico.

line-height: 1.8;
text-align: justify;
font-style: italic;

Unidades para tamanho

  • px: valor fixo em pixels.
  • em: relativo ao tamanho da fonte do elemento pai.
  • rem: relativo ao tamanho da fonte raiz do documento.

Unidades relativas, como rem, facilitam a adaptação do texto às preferências de leitura.
