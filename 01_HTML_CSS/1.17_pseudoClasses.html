Pseudoclasses em CSS

Pseudoclasses selecionam elementos com base em seu estado ou posição, sem precisar adicionar classes manualmente no HTML. Elas começam com dois-pontos, como :hover.

Estados de links e interação

Experimente passar o cursor ou usar o teclado para focar o link. As pseudoclasses :hover e :focus indicam esses estados.

Passe o cursor ou navegue até este link

:visited seleciona links já visitados e :active se aplica enquanto o link está sendo ativado.

Elementos em uma lista

:first-child, :last-child e :nth-child() selecionam elementos de acordo com sua posição.

Estados de formulário

:focus destaca o campo ativo e :checked seleciona um controle marcado.

Selecionando elementos disponíveis
