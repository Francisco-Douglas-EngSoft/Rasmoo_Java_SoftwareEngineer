Box Model do CSS

No CSS, cada elemento é representado como uma caixa. O box model descreve como o tamanho e o espaço dessa caixa são calculados.

MARGEM
BORDA
PADDING
CONTEÚDO

As quatro partes da caixa

  • Conteúdo: texto, imagem ou outros elementos. As propriedades width e height definem suas dimensões.
  • Padding: espaço entre o conteúdo e a borda.
  • Border: contorno ao redor do conteúdo e do padding.
  • Margin: espaço externo que separa a caixa de outros elementos.

Exemplo de cálculo

Com o padrão box-sizing: content-box, uma caixa com largura de conteúdo de 200px, padding de 20px em cada lado e borda de 4px em cada lado ocupa 248px no total:

200px + 20px + 20px + 4px + 4px = 248px

Usando border-box

Com box-sizing: border-box, a largura definida já inclui conteúdo, padding e borda. A caixa abaixo tem 200px de largura total:
