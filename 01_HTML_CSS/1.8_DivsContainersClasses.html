Divs, Containers e Classes

A tag <div> agrupa elementos sem adicionar significado semântico. Classes permitem identificar e estilizar grupos reutilizáveis.

Primeiro bloco

Este conteúdo está agrupado em uma div com a classe card.

Segundo bloco

As classes card e destaque podem ser usadas em vários elementos.

Quando usar cada elemento?

Use <div> para agrupamentos genéricos e prefira elementos semânticos, como <section> e <main>, quando eles descrevem melhor o conteúdo.
