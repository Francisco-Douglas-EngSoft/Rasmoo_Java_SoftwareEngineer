Imagens, Vídeos e Áudios em HTML

Imagens

A tag <img> exibe uma imagem. O atributo alt descreve seu conteúdo para leitores de tela e quando a imagem não carrega.

Vídeos

A tag <video> pode oferecer controles para reproduzir, pausar e ajustar o volume.

Áudios

A tag <audio> com controls permite controlar a reprodução do som.
