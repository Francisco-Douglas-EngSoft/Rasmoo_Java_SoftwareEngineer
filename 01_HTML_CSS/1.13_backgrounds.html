Backgrounds em CSS

As propriedades de background definem o fundo de um elemento: podem aplicar cores, imagens, controlar seu posicionamento e ajustar sua repetição.

Cor de fundo

background-color aplica uma cor sólida ao fundo do elemento.

Fundo com cor sólida
background-color: #dceeff;

Imagem de fundo

background-image aplica uma imagem. Neste exemplo, o gradiente é criado em CSS, sem depender de um arquivo de imagem externo.

Fundo com gradiente
background-image: linear-gradient(120deg, #174a73, #64b5d8);

Tamanho e posicionamento

background-size: cover amplia o fundo para cobrir a área. background-position define onde ele fica posicionado.

Gradiente centralizado e cobrindo o bloco
background-size: cover;
background-position: center;

Repetição e combinação

background-repeat define se a imagem se repete. Também é possível combinar imagem e cor de fundo.

Padrão repetido criado com CSS
background-repeat: repeat;
background-color: #fff3df;
