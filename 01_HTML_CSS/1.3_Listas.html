Listas em HTML

Lista não ordenada

Use <ul> quando a ordem dos itens não importa:

  • HTML
  • CSS
  • JavaScript

Lista ordenada

Use <ol> quando os itens seguem uma sequência:

  1. Planejar a página
  2. Escrever o HTML
  3. Testar no navegador

Lista de descrição

Use <dl> para associar termos a suas descrições:

HTML
Linguagem de marcação usada para estruturar páginas web.
CSS
Linguagem usada para estilizar páginas web.
