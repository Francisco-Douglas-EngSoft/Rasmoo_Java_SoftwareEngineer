Responsividade em CSS

Uma página responsiva se adapta a diferentes tamanhos de tela e dispositivos.

O que é responsividade?

Design responsivo organiza o conteúdo para que ele continue legível e utilizável em celulares, tablets e computadores. O viewport configurado no <head> permite que a página use a largura real do dispositivo.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Layout flexível

Contêineres fluidos e unidades relativas ajudam o conteúdo a acompanhar o espaço disponível, em vez de depender de uma largura fixa.

Conteúdo adaptável

Este cartão se ajusta à largura do contêiner.

Espaçamento fluido

O layout reorganiza os cartões conforme o espaço disponível.

Leitura confortável

O conteúdo mantém limites de largura para facilitar a leitura.

Imagens flexíveis

Use max-width: 100% para impedir que imagens ultrapassem os limites do contêiner.

Paisagem responsiva

Media queries

Media queries aplicam estilos conforme características da tela. Reduza a largura da janela para ver os cartões em uma única coluna.

@media (max-width: 600px) {
    .cartoes {
        grid-template-columns: 1fr;
    }
}
