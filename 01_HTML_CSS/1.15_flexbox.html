Flexbox em CSS

Flexbox é um modelo de layout unidimensional. Ele organiza itens em uma linha ou coluna e facilita o alinhamento e a distribuição do espaço.

Eixos e direção

O eixo principal é definido por flex-direction. O eixo transversal fica perpendicular ao principal.

1
2
3
display: flex;
flex-direction: row;

Justificar e alinhar

justify-content distribui itens no eixo principal. align-items alinha os itens no eixo transversal.

Item A
Item B
Item C
justify-content: space-around;
align-items: center;

Espaçamento com gap

A propriedade gap cria espaço entre os itens, sem precisar adicionar margens individuais.

CSS
JavaScript
display: flex;
gap: 16px;

Quebra de linha

Com flex-wrap: wrap, os itens passam para outra linha quando não há espaço suficiente no contêiner.

Item 2
Item 3

Propriedades dos itens

Itens podem crescer ou encolher com flex-grow e flex-shrink. A propriedade flex é uma forma abreviada de configurar esses comportamentos e a base do item.

Cresce para ocupar o espaço disponível
